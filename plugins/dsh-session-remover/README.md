# dsh-session-remover（会话删除，回收站可还原）

在侧栏会话行的「…」菜单中增加「删除对话」与「批量删除…」，把对话及其子代理会话移入 **Windows 回收站**，需要时可以还原。

- 包名：`dsh-session-remover@1.0.1`（npm）
- 上游：https://github.com/sailoumili/dsh-session-remover
- 兼容：DSH 0.1.7 及以上，网页版与桌面版通用；仅支持 Windows
- 无第三方运行时依赖；包内 `cordis.patch.yml` 完整，安装后不会出现启动崩溃

## 为什么换掉上一个插件

原 `better-dsh-session-deletetool` 在本机 dsh 0.2.x 上存在两处不适配：

1. 批量对话框固定显示「读取失败：HTTP 200」（客户端把非 JSON 响应编码为 `HTTP <状态码>`，根因未确认）；
2. 依赖的 `sessionQuery` 服务在当前版本不可用，家族树读不到子智能体。

该插件已卸载，本目录替换为 `dsh-session-remover`。

## 安装

```sh
dsh plugin install dsh-session-remover --profile web
# 重启 dsh web
```

桌面版需单独安装一次（两个 profile 的依赖不共享）：

```sh
dsh plugin install dsh-session-remover --profile desktop
```

## 用法

1. 鼠标移到侧栏任一会话行，点行尾「…」。
2. 菜单最后两项是「删除对话」与「批量删除…」。
3. 单条：点「删除对话」→ 确认框点「确定」→ 页面自动刷新，该行消失。
4. 批量：点「批量删除…」→ 勾选目标（支持全选/全不选）→ 勾选确认项 → 点「删除选中的 N 个」→ 再次确认后逐条删除。

## 还原

打开 Windows 资源管理器 → 回收站 → 右键对应会话文件夹 → 还原 → 重启 DSH。

注意：删除是"移入回收站"而非抹除——同盘移动、不复制数据，`.dsh` 内不留副本。还原后投影缓存会自动重建；工作区记账与归档集合的清理**不会**同步恢复，因此还原的对话会归入侧栏「未分组」。

## 已知限制

- 仅支持 Windows，依赖系统自带的 `cscript.exe` 完成移入回收站。
- 目标磁盘没有回收站时（FAT/exFAT、网络盘、U 盘，或该盘回收站被关闭）插件**拒绝删除**，不会退化为永久删除。处理办法：把会话目录搬到本地磁盘，或先在该盘删除任一文件以启用回收站，再重试。
- 回收站清空后不可还原；回收站有容量上限，超出配额时 Windows 会丢弃最早的项。
- 删除当前打开的对话时，会先停止其运行中的任务并落盘，无需重启 DSH。
- 由 fork 产生的分叉会话属独立对话，不会被连带删除。
